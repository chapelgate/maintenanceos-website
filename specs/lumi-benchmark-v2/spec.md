# LUMI Benchmark V2

## Goal
Create a reproducible, evidence-backed, GPU-efficient evaluation harness for the MaintenanceOS family using the awarded EuroHPC LUMI-G allocation.

## Scope
- synthetic data only;
- MaintenanceOS/ReceptionOS shared intelligence and eight industry contexts;
- deterministic safety layer remains authoritative;
- no production voice wiring;
- no live customer/resident data;
- no unrelated product workloads.

## Acceptance
- benchmark corpus integrity gate rejects identifier-only duplicates and split leakage;
- development, selection-validation and hidden-final sets are separated by family;
- deterministic hard-gate scoring covers safety, privacy, actions and claims;
- model results can be overlaid with the canonical deterministic safety engine;
- model candidates are preflighted before material GPU spend;
- LUMI jobs are bounded and record allocation evidence;
- GPU usage is selected by measured value, not quota consumption.
