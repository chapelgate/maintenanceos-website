# Assigning Repairs to Contractors

MaintenanceOS helps you assign the right contractor to each repair using smart matching based on trade, location, availability, and performance.

## Manual Assignment

1. Open the repair → **Assign Contractor** button
2. See ranked contractor suggestions:
   - ✅ Matching trade specialism
   - ✅ Covers property postcode
   - ✅ Available (no conflicting jobs)
   - ✅ Good performance score
   - ✅ Certifications up to date
3. Select contractor → **Confirm Assignment**

Contractor receives instant notification (email + portal + SMS if emergency).

## Smart Matching Algorithm

Contractors are ranked by:

| Factor | Weight | Details |
|--------|--------|---------|
| Trade match | 30% | Exact category match = 100%, related = 50% |
| Coverage area | 25% | Postcode district match = 100%, adjacent = 60% |
| Current workload | 20% | Fewer active jobs = higher score |
| Performance score | 15% | First-time fix rate, response time, satisfaction |
| Certification status | 10% | All required certs valid = 100% |

**Safety latch repairs** only show contractors with valid certifications for the specific risk (e.g., Gas Safe for gas emergencies).

## Bulk Assignment

For multiple repairs at the same property or area:
1. Go to **Repairs → List View**
2. Filter by status "Triaged", property, or area
3. Select multiple → **Bulk Assign**
4. Choose contractor or let system auto-assign each

## Contractor Availability

Contractors set availability in their portal:
- **Working hours** (e.g., Mon–Fri 08:00–17:00)
- **Emergency availability** (24/7 or specific hours)
- **Time off** (holidays, training days)
- **Capacity** (max concurrent jobs)

MaintenanceOS respects these when suggesting assignments.

## Reassignment

If a contractor cannot complete a repair:
1. Open repair → **Reassign**
2. Select reason (Unavailable, Declined, Wrong Trade, Performance)
3. System suggests alternatives (excluding original contractor)
4. New contractor notified; original contractor notified of removal

**Audit note:** Reassignment reason and timestamp recorded automatically.

## Emergency Assignment

For Safety Hold repairs cleared by Safety Officer:
- Only contractors with matching emergency certifications shown
- Assignment creates **Emergency** priority job
- Contractor must acknowledge within 30 minutes
- SLA clock starts at Safety Hold clear time

## Subcontractor Management

If your contractor uses subcontractors:
1. Main contractor assigns sub in portal
2. MaintenanceOS tracks sub-contractor on repair record
3. Primary contractor remains responsible for SLA and quality
4. Sub-contractor certifications must be uploaded by primary
