# Release Notes

Stay up to date with what's new in MaintenanceOS. Release notes are published with every deploy.

## Current Version

**v0.14.0** — Released 2025-02-09
**Channel:** Pre-launch Early Access

## v0.14.0 (2025-02-09)

### New Features
- **Tenant Portal Welsh Language** — Full Cymraeg translation toggle
- **Emergency Rota Management** — Visual rota builder with drag-and-drop
- **API: Batch Repair Create** — Create up to 50 repairs in one request
- **Webhook: `tenant.portal_message`** — Real-time tenant messages

### Improvements
- Repair list: Added "Safety Latch" filter and column
- Contractor portal: Offline indicator + pending sync count
- Dashboard: SLA compliance widget now shows trend (7d/30d)
- Gas Safety: Auto-create remedial repair from "At Risk" findings
- Mobile PWA: Biometric authentication option (Face ID/Touch ID)

### Fixes
- Fixed: EPC exemption expiry not triggering warning at 30 days
- Fixed: Contractor bulk import failing on special characters in names
- Fixed: Tenant portal magic link expiring early on iOS Safari
- Fixed: Report export timeout on portfolios >500 properties
- Fixed: Webhook retry not respecting `Retry-After` header

### Security
- Updated: All dependencies patched (no high/critical CVEs)
- Added: Rate limiting on `/api/v1/auth/magic-link` (10/min/IP)
- Hardened: CSP `script-src` nonce rotation on every deploy

## v0.13.0 (2025-01-26)

### New Features
- **HMO Licence Tracking** — Full licence lifecycle with condition monitoring
- **Fire Risk Assessment Module** — Findings → Tasks auto-creation
- **Contractor Compliance Dashboard** — Cert/insurance expiry tracking
- **API: Compliance Endpoints** — `/compliance/gas`, `/epc`, `/fire`, `/hmo`

### Improvements
- Safety Latch: Added "Winter Heating" rule (Oct–Mar, vulnerable tenants)
- Tenant Portal: Step-by-step repair form option
- Reports: Portfolio Health score algorithm updated
- Mobile: Camera EXIF stripping for privacy

### Fixes
- Fixed: Gas Safe API verification failing on new certificate format
- Fixed: Quote approval email not sending when auto-approved
- Fixed: Property import CSV not handling Scottish postcodes
- Fixed: Dashboard SLA widget showing stale data after timezone change

- **Slack/Teams Integration** — Rich notifications with actions

### Fixes
