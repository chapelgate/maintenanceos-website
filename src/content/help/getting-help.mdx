# Getting Help & Support

Multiple channels to get the help you need, when you need it.

## Self-Service (Fastest)

### Help Centre (This Site)
- **Search:** Top-right search bar filters all articles
- **Categories:** Browse by Getting Started, Daily Operations, Compliance, etc.
- **Bookmark:** Save articles for quick access
- **Feedback:** "Was this helpful?" on every article

### In-App Help
- **Contextual help:** `?` icon on every page → Relevant articles
- **Tooltips:** Hover any field for explanation
- **Guided tours:** First-time walkthroughs (replayable via Help → Tours)
- **Keyboard shortcuts:** `?` anywhere → Shortcut cheatsheet

### Video Tutorials
- **YouTube channel:** `youtube.com/@MaintenanceOS`
- **Topics:** Setup, repairs, compliance, reports, integrations
- **Length:** 2–5 minutes each
- **Captions:** English, Welsh

## Direct Support

### Email Support
**support@maintenanceos.co.uk**

| Plan | Response Target | Hours |
|------|----------------|-------|
| **Starter** | 24 hours | Mon–Fri 9am–5pm GMT |
| **Professional** | 4 hours | Mon–Fri 9am–5pm GMT |
| **Enterprise** | 1 hour | 24/7/365 |

**Include for fastest response:**
- Workspace name / subdomain
- Your email
- Issue description + steps to reproduce
- Screenshots / error messages
- Browser / device
- Time (with timezone)

### In-App Chat (Professional + Enterprise)
- **Help → Chat** — Connects to support agent
- **Business hours:** Mon–Fri 9am–5pm GMT
- **Transcript** emailed after close
- **Co-browsing** (opt-in) — Agent sees your screen

### Phone Support (Enterprise Only)
- **Dedicated line** — Provided on onboarding
- **24/7** for critical issues (safety, data loss)
- **Callback request** via in-app chat

## Emergency Contacts

**Critical safety issues only (gas, fire, structural, life safety):**

| Channel | Details |
|---------|---------|
| **Phone** | +44 20 3XXX XXXX (Enterprise) / 0800 111 999 (Gas) / 999 (Fire/Police) |
| **Email** | emergency@maintenanceos.co.uk (monitored 24/7) |
| **In-app** | Safety Latch → "Call Emergency Services" button |

**Do not use emergency channels for:** General questions, billing, feature requests, non-urgent bugs.

2. **Admin onboarding call** (30 min, Professional + Enterprise)

4. **First repair walkthrough** (guided)

### Ongoing Training

- **Compliance updates** — Quarterly regulatory changes
- **Custom training** (Enterprise) — Tailored to your workflow

## Escalation Path

If standard support doesn't resolve your issue:

1. **Reply to support email** — "Please escalate"
2. **Request Senior Support Engineer** — 2-hour response (Professional+)
3. **Customer Success Manager** (Enterprise) — Direct contact
4. **Formal complaint** — `complaints@maintenanceos.co.uk` — 5-day acknowledgment
5. **ADR** — Alternative Dispute Resolution (Enterprise contracts)
