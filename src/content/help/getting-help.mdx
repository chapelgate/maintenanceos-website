# Getting Help & Support

MaintenanceOS is pre-launch. There is no public support phone and this page is not a live support desk.

## Self-Service (Fastest)

### Help Centre (This Site)
- **Search:** Top-right search bar filters all articles
- **Categories:** Browse by Getting Started, Daily Operations, Compliance, etc.
- **Bookmark:** Save articles for quick access
- **Feedback:** "Was this helpful?" on every article

### In-App Help
- **Contextual help:** `?` icon on every page → Relevant articles
- **Tooltips:** Hover any field for explanation
- **Guided tours:** First-time walkthroughs (replayable via Help → Tours)
- **Keyboard shortcuts:** `?` anywhere → Shortcut cheatsheet

### Video Tutorials
- **YouTube channel:** `youtube.com/@MaintenanceOS`
- **Topics:** Setup, repairs, compliance, reports, integrations
- **Length:** 2–5 minutes each
- **Captions:** English, Welsh

## Direct Support

### Email
Early-access questions: **early-access@maintenanceos.co.uk**

There is no published response-time table. Not a live SLA.

### In-app chat
In-app chat is not available on this pre-launch site.

### Phone support
There is no public support phone. No dedicated line is published. Not a live support desk.

## Emergency contacts

For life safety, use the public emergency services. MaintenanceOS does not publish a support phone and does not monitor a round-the-clock desk.

| Channel | Details |
|---------|---------|
| **Gas emergency** | 0800 111 999 (National Gas Emergency Service) |
| **Fire or immediate danger** | 999 |

Do not treat this help page as a monitored emergency desk.
