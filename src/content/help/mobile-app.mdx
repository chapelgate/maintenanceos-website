# Mobile App & PWA

MaintenanceOS does not publish an app host on this site. Not a live app.

## What Is a PWA?

A Progressive Web App combines the best of web and native apps:
- **Installable** — Add to home screen (no App Store)
- **Offline-capable** — Works without connection
- **Push notifications** — Real-time alerts
- **Auto-updates** — Always latest version
- **Secure** — HTTPS only, service worker controlled

## Installing the PWA

No app host is published, so there is nothing to install from this site. Not a live app.

## Offline Support

### What Works Offline
- **View** assigned repairs (cached at login)
- **Update status** (En Route, On Site, Completed) — queued
- **Take photos** — stored locally, uploaded when online
- **View property details** (cached)
- **Read compliance certificates** (cached)

### What Requires Connection
- **New repairs** (create, assign)
- **Search** properties/contractors
- **Reports** (analytics, exports)
- **Settings** changes
- **Real-time chat** with tenant/manager

### Conflict Resolution
- Last-write-wins for status updates
- Photos always upload (append-only)
- Manager notified of offline edits on sync

## Push Notifications

### Enable Notifications
1. Login → **Settings → Notifications → Push**
2. Allow permission prompt
3. Select event types:
   - Repair assigned to me
   - Status changes on my repairs
   - Safety latches (emergency)
   - Compliance deadlines
   - Messages from tenant/manager

### Notification Payload
- Title, body, action buttons
- Deep link to repair in app
- Works when app closed (service worker)

### Platform Notes
- **iOS:** Requires iOS 16.4+, added to Home Screen
- **Android:** Full support Chrome 70+
- **Desktop:** Chrome/Edge/Safari (with PWA installed)

## Camera & Media

- **Photo capture:** Direct camera access (`<input capture="environment">`)
- **Compression:** Auto-resize to 2MB max before upload
- **EXIF stripping:** GPS/location data removed for privacy
- **Multi-photo:** Select multiple, upload in background

## Biometric Authentication

**Optional** (Settings → Security → Biometric):
- Face ID / Touch ID (iOS)
- Fingerprint / Face Unlock (Android)
- Windows Hello (Desktop)
- Replaces magic link for 30 days
- Falls back to email if failed

## Background Sync

- **Periodic sync:** Every 15 minutes when online
- **On connectivity change:** Immediate sync
- **Battery aware:** Defers if low power mode
- **Data usage:** ~50KB/sync (text only), photos separate

## Storage Management

- **Cache limit:** 50MB (configurable)
- **Auto-evict:** Oldest unused data first
- **Manual clear:** Settings → App → Clear Cache
- **Photos:** Never auto-deleted (user controls)

## Updates

- **Silent update:** Service worker fetches new version in background
- **Prompt:** "New version available — Refresh" banner
- **Force update:** Critical security patches auto-refresh
- **Version check:** On app focus + periodic

## Troubleshooting

| Issue | Fix |
|-------|-----|
| "App won't install" | Use HTTPS, clear browser data, try different browser |
| "Notifications not working" | Check OS permissions, re-enable in app settings |
| "Offline changes lost" | Don't clear browser data; contact support for recovery |
| "White screen on launch" | Hard refresh (Ctrl+Shift+R), check internet, reinstall |
| "Camera not working" | Check browser permissions, try native camera app first |
