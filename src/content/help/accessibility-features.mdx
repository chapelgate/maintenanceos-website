# Accessibility Features

MaintenanceOS is designed to be accessible to everyone. We are working toward WCAG 2.2 Level AA; an independent audit is planned before public launch.

## Current Accessibility Status

**Target:** WCAG 2.2 AA — independent audit planned pre-launch
**Audit:** Independent audit planned pre-launch
**Known gaps:** Documented at `/accessibility/`

## Dashboard & Manager Portal

### Keyboard Navigation
- **Tab order:** Logical, follows visual layout
- **Focus indicators:** Visible 3px accent ring on all interactive elements
- **Skip links:** "Skip to main content" on every page
- **Landmarks:** `<main>`, `<nav>`, `<aside>`, `<header>`, `<footer>` properly marked
- **Shortcuts:** `Alt+1` Dashboard, `Alt+2` Repairs, `Alt+3` Properties, `Alt+4` Compliance, `Alt+5` Reports

### Screen Reader Support
- **ARIA labels** on all icon-only buttons
- **Live regions** for status updates (repair count, notifications)
- **Table headers** scoped correctly (`<th scope="col">`)
- **Form labels** explicitly associated (`<label for>`)
- **Error announcements** via `aria-live="assertive"`
- **Modal dialogs** trap focus, announce title

### Visual Design
- **Colour contrast:** 4.5:1 minimum (text), 3:1 (UI components)
- **No colour-only information** — Icons + text, patterns + colour
- **Text scaling:** Supports 200% zoom without horizontal scroll
- **Reduced motion:** Respects `prefers-reduced-motion`
- **High contrast mode:** Windows High Contrast / forced colours supported

## Tenant Portal

### Additional Features
- **Simple language** — Plain English, no jargon
- **Step-by-step repair form** — One question per screen option
- **Voice input** — HTML5 speech recognition for description field
- **Large touch targets** — 48×48px minimum
- **Welsh language** — Full Cymraeg translation (toggle in header)

### Welsh Language Support
- All user-facing text translated
- Date formats: DD/MM/YYYY (Welsh), DD MMM YYYY (English)
- Currency: £ (both)
- Right-to-left: Not required for Welsh

## Contractor Portal

- Simplified interface — fewer navigation items
- Large buttons for status updates
- Photo upload with camera access
- Offline-capable (PWA) — queue updates when reconnected

## API & Developer Tools

- **API docs:** Keyboard navigable, screen reader compatible
- **Webhook payloads:** Structured, predictable, documented
- **Error messages:** Clear, actionable, no jargon

## Testing & Validation

### Automated (CI)
- **axe-core** on every PR (0 critical, 0 serious)
- **Lighthouse CI** accessibility score ≥ 95
- **TypeScript** strict mode catches missing ARIA

### Manual (Pre-release)
- **Screen readers:** NVDA (Windows), VoiceOver (Mac/iOS), TalkBack (Android)
- **Keyboard only:** Full workflow testing
- **Zoom:** 200%, 400% testing
- **Colour blindness:** Simulators (Protanopia, Deuteranopia, Tritanopia)
- **Voice control:** macOS Voice Control, Windows Speech Recognition
