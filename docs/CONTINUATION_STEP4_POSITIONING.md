# Continuation Step 4 — positioning and message refinement

**Date:** 2026-09-27
**Owner:** MOS Positioning + Website Manager
**Baseline:** website main `46fcce79aa49905bd78f1852302dc7a66a095f69`
**Claims source:** `PRODUCT_CLAIMS_REGISTER.md`

## Decision

MaintenanceOS should not compete on unsupported “instant live AI receptionist” or
24/7 automation claims. Public competitor research shows that category leaders
lean heavily on instant setup, always-on answering, bookings, integrations and
live testing. MaintenanceOS remains pre-launch, so its public message stays on
the differentiated evidence it can defend:

- UK maintenance intake rather than generic phone answering;
- structured repair/work intake rather than loose call notes;
- critical cases separated from routine jobs;
- deterministic safety/approval boundaries;
- authorised people retain consequential decisions;
- traceable operational records.

## Changes

- tightened the canonical one-sentence value proposition;
- aligned the homepage lede to that statement;
- made public voice-status copy provider-neutral;
- removed a named competitor comparison from public Industries copy;
- retained the primary promise `Turn maintenance requests into clear, controlled work.`;
- retained `Create from website` as the primary CTA;
- retained PRE-LAUNCH / UNDER TEST honesty.

## Guardrails

Buyer-facing page source must not name a voice provider or competitor as part of
the current value proposition. Provider and competitor detail belongs in internal
engineering/research evidence, not in public positioning.

No capability status changed in this step.
