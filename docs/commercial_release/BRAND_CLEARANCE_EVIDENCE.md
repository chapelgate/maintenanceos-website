## Release-gate conclusion

The name **MaintenanceOS / Maintenance OS cannot be treated as cleared** from public research alone.

Material overlap is already proven:

1. **Maintenance OS — Bourne & Co, County Durham, UK**  
   Public site: https://maintenance-os.com/  
   The site actively sells a property-maintenance system to independent letting agents for £1,495. It describes an admin portal, contractor portal, tenant reporting widget, automated emails, compliance tracking and property/repair workflows. The page states that the product was built by Bourne & Co in County Durham and is already offered commercially.
2. **Hivenox Maintenance OS**  
   Public site: https://hivenox.com/maintenance-os  
   Hivenox markets a facilities/property-maintenance platform using the words **Maintenance OS**, including residential/public-housing work orders, AI triage, SLAs, contractors, evidence, claims and asset history.
3. **maint-os.com — MaintenanceOS**  
   Public site: https://maint-os.com/  
   A separate product uses **MaintenanceOS** for machine/equipment maintenance management, scheduling, issue documentation and parts.

These products are not evidence of infringement by Chapelgate. They are evidence that identical or near-identical naming is already in real software/maintenance commerce and therefore professional clearance is necessary before general promotion.

## Official UKIPO/GOV.UK pre-filing requirements

GOV.UK says applicants should:
- choose the relevant classes/terms for the goods and services intended;
- search the UK trade-mark database for the same or similar marks;
- obtain professional advice if a same or similar mark is found.

Source: https://www.gov.uk/how-to-register-a-trade-mark/before-you-apply

GOV.UK also explains that the IPO searches for same/similar earlier marks and may notify earlier rights holders; opposition can lead to withdrawal, negotiation or legal defence.

Sources:
- https://www.gov.uk/how-to-register-a-trade-mark/after-you-apply
- https://www.gov.uk/government/publications/process-for-applying-to-register-for-a-trade-mark/trade-marks-timeline

## Classes/terms that professional clearance should at least test

This is a **search scope, not a filing recommendation**.

### Class 9 — software
Recent UKIPO journal entries for property/business software place downloadable/recorded computer software, property-management software, workflow software, AI software, messaging software and related applications in Class 9.

Example official UKIPO journal source:
https://www.ipo.gov.uk/tm/t-tmj/tm-journals/2026-007/UK00004330144.html

### Class 42 — SaaS / hosted software / software development
Recent UKIPO journal entries place SaaS, PaaS, AI-as-a-service, hosted/non-downloadable software, software development and software integration in Class 42.

Example official UKIPO journal sources:
- https://www.ipo.gov.uk/tm/t-tmj/tm-journals/2026-007/UK00004330144.html
- https://www.ipo.gov.uk/t-tmj/tm-journals/2026-037/UK00004435426.html

### Classes to assess only if Chapelgate's actual commercial scope needs them
- **Class 37:** building/maintenance/repair services if MaintenanceOS itself is sold as or bundled with the provision of maintenance services rather than software only.
- **Class 35:** business administration/data-processing/management services if separately supplied under the mark.
- Other classes should be driven by the actual five-year commercial plan, not added speculatively.

A recent UKIPO property-management filing demonstrates that property-management businesses can span Classes 9, 36, 37 and 42 depending on the actual goods/services claimed:
https://www.ipo.gov.uk/t-tmj/tm-journals/2026-037/UK00004435387.html
