# iso27001 — Operating Rhythm — SHADOW / UNCERTIFIED / INTERNAL DRAFT

⚠️ **SHADOW / UNCERTIFIED / INTERNAL DRAFT — NOT FOR TENDER OR CERTIFICATION CLAIMS** ⚠️

This operating rhythm is an INTERNAL SHADOW TEMPLATE. It does NOT constitute UKAS-accredited ISO 27001 certification. It cannot substitute for formal certification in UK public sector tenders (PPN 09/14, PPN 09/23, Procurement Act 2023 'or equivalent' requires UKAS-accredited certification or independently verified equivalence). The Statement of Applicability is UNSIGNED and carries no regulatory weight.

Recurring checks that keep this standard true day to day, wired to existing Dell timers/jobs where possible:

- Verify ISMS scope and interested parties register remains current on each release cycle (wired to factory-tasks release gates).
- Re-check Clauses 4-10 documentation against product repos quarterly; confirm no drift from ISO 27001 alignment.
- Update risk assessment and treatment plan per product on each release cycle; link to FAILURE-LOG.md entries.
- Verify competence/awareness records are current per product; update competence matrix on annual review.
- Confirm documented information control process is enforced (versioning, access, review) per product release.
- Test change management process with risk assessment on each release; verify ISO 27001 Clause 8 alignment.
- Review internal audit programme progress; schedule and conduct internal audit per annual cycle.
- Prepare management review inputs (monitoring results, audit findings, corrective actions) before each council meeting.
- Update Statement of Applicability draft on each release cycle; document any N-A control changes.
- Track certification progress: if pursuing certification, monitor Stage 1/Stage 2 audit scheduling with CB; record in TENDER-REGISTER.md.

Where possible, wire to existing Dell timers/jobs:
- Release gate checks (factory-tasks/ release cycle)
- Quarterly compliance review (aligned to council cycles)
- Annual appraisal/review (for competence/awareness)
- Failure log review (FAILURE-LOG.md for nonconformity/CAPA)
