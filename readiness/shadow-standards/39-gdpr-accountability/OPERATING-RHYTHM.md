# 39-gdpr-accountability — Operating Rhythm

Recurring checks that keep this standard true day to day:
- Verify 13 DPIA drafts remain current on each release; complete DPO sign-off
- Compile and verify ROPA per product from product documentation on each release
- Review and update retention schedule per product; enforce automated deletion
- Test SAR process response time and update documentation
- Test data breach notification process (≤72 hours to ICO); review incident records
- Review international transfers map (SCCs / adequacy) for changes
- Update processor/sub-processor list from architecture diagrams
- Record ICO fee payment status or maintain park decision

Wire to existing Dell timers/jobs where possible.
